# Отчет об устранении инцидентов (NexusMonitor)

---

### Инцидент №1: Отсутствие базовых зависимостей
**СИМПТОМ:**
`ModuleNotFoundError: No module named 'pydantic_settings'` при попытке запуска бэкенда.
**ПРИЧИНА:**
Разработчик использовал библиотеку `pydantic-settings` для управления конфигурацией, но не включил её в файл зависимостей `requirements.txt`.
**РЕШЕНИЕ:**
Пакет `pydantic-settings` добавлен в `backend/requirements.txt`.
**КОММИТ:**
`98d081b`

---

### Инцидент №2: Отсутствие драйвера PostgreSQL
**СИМПТОМ:**
`ModuleNotFoundError: No module named 'psycopg2'` при попытке запуска приложения.
**ПРИЧИНА:**
Для работы SQLAlchemy с базой данных PostgreSQL требуется драйвер-адаптер, который не был указан в зависимостях.
**РЕШЕНИЕ:**
Пакет `psycopg2-binary` добавлен в `backend/requirements.txt`.
**КОММИТ:**
`51c5579`

---

### Инцидент №3: Ошибка прав доступа к директории логов
**СИМПТОМ:**
`PermissionError: [Errno 13] Permission denied: '/var/log/nexus_monitor_production/'`
**ПРИЧИНА:**
В конфигурации логирования был жестко прописан абсолютный путь к системной директории `/var/log/`, запись в которую запрещена для обычного пользователя.
**РЕШЕНИЕ:**
Путь к логам изменен на относительный (`logs/`), что позволяет приложению создавать файлы внутри своей директории.
**КОММИТ:**
`d712fa5`

---

### Инцидент №4: Некорректный порт API в настройках фронтенда
**СИМПТОМ:**
Фронтенд не может получить данные от бэкенда, в консоли браузера ошибки сетевого подключения.
**ПРИЧИНА:**
В конфигурационном файле фронтенда `.env` был ошибочно указан порт `8001`, в то время как бэкенд-сервер запускается на стандартном порту `8000`.
**РЕШЕНИЕ:**
Значение `VITE_API_URL` во `frontend/.env` изменено на `http://localhost:8000/api`.
**КОММИТ:**
[будет обновлено после пуша]
